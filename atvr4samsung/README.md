# atvr4samsung Companion Bridge

Pair the native iPhone Control Center Remote with an emulated Apple TV and
relay its controls to a Samsung Tizen television.

Features provided by the pinned upstream release include swipe navigation,
Home, Menu/Back, Select, playback, volume/mute, power/Wake-on-LAN, and keyboard
input. Host networking is required for Companion Link mDNS discovery.

Read the **Documentation** tab for the required TLS trust and pairing sequence.
